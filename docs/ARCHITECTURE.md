# 实现与性能边界

## 控制链

目标 bundle + SDK 版本/UUID → SDK 主通道配置 → 下次发布选择 Opus/192 或恢复原版 → 原生主源归属检查 → 编码线程设置 CBR/DTX → SDK 实际统计 → 仅展示已确认的状态。

原生层只替换已确认的可写、不可执行数据页上的一个虚表编码回调指针，不修改指令页、不改变页权限。完整虚表和局部指令签名只是版本护栏，不能代替新版本适配或证明所有组合安全。

原版模式保存/恢复宿主的码率、声道及编码类型；原生模式保存的 VBR、约束模式、DTX 会在对应对象的恢复路径上还原。退出并不再注入是彻底恢复方式。注入库的多个版本不能叠加。

## UI

340 pt 最大宽度，遵循 UIWindow 安全区；头部固定、正文滚动，不做覆盖全屏的透明拦截层。面板打开时隐藏悬浮按钮，避免其盖住操作区。支持字体倍率 1–1.35；更大的系统倍率在该上限处限制，小屏仍能滚动查看。没有宣称覆盖所有辅助功能字号。

目标、SDK 读回、原生参数、实际发送是不同状态。只有原生参数匹配当前发布及选择时才显示 Opus CBR；无新鲜统计不显示连接成功。

## 资源占用

- 无新增线程、服务、开机自启或网络轮询。
- 既有 2 秒主线程维护定时器用于 UI/尚未绑定的对象链；绑定成功不反复扫描。
- 后台不刷新 UI；面板收起时不刷新动态文字。布局只有窗口、尺寸或字体倍率变化时重算。
- 状态文件最多每 6 秒脏写一次；音频编码回调中没有文件写入、UI 或字符串格式化。
- 参数已经匹配时不重复调用 Opus 控制接口，不覆盖 SDK 自适应降档。

这些是源码行为，不是 CPU/内存实机对比基准。本次没有性能测量，不声称具体占用下降比例。

## 本地数据

- UserDefaults：`PinkCatAudio.targetKbps.192.v1`，只记住 0/192。
- 宿主沙盒 `Documents/PinkCatAudio/status.json`：数值诊断、SDK 版本、状态，不含录音、账号或密码。
- 用户点击复制时向 UIPasteboard 写入界面显示的单个联系方式，不读取剪贴板。

## 错误提示

顶层 401 为已发现旧库冲突；201–203 为 SDK 接口/初始化，301–304 为本地诊断/UI 异常。原生 410–415 分别为签名不匹配、页面不可写、格式不匹配、控制失败并尝试恢复、已有虚表修改、恢复失败。界面用简洁提示，细节保存在本地诊断文件。
