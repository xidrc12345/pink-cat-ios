## 本地验收与限制

最终目录内的 `validation/` 保存构建、Mach-O/ad-hoc 校验和模拟断言结果。旧的 192 原生头未修改，模拟结果仍不是 iOS 真机 ABI 或收发证明。

本次未连接手机、未注入、未录音；持续 192、房间接收兼容、UIKit 真机绘制/触控与性能占用仍需验收。界面预览图是设计图，不是真机截图。

## 准备公开

1. 本源码目录可解压为仓库根目录；不要把整个工作站目录或其他交接包上传。
2. 仓库内容仅为自行编写的移动端库、构建/测试工具、公共 ABI 声明、版本匹配特征与文档。
3. 不上传 `samples/`、原应用/SDK、私钥、卡密数据、PC 源码、服务器配置、编译器和临时证据。
4. 二进制放 GitHub Release 附件；仓库 `.gitignore` 默认忽略构建输出。
5. 不把这个公开移动端项目描述为 PC 正式版源码或声称已实机验收。

源码与二进制对应 v1.0.0；二进制同时位于 releases/v1.0.0 和 GitHub Release 附件。
