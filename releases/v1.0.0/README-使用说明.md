# pink cat · iOS 1.0.0

192 kbps CBR 专用版，只有“192 kbps · CBR / 恢复原版”。

## 替换
1. 完全退出 TT，移除旧注入项。不要叠加加载。
2. 用本目录 PinkCatAudio.dylib 替换旧库，经你现有巨魔工具注入，再启动 TT。
3. 点可拖动的 pink cat。首次默认192，后续记住你的选择。切换后下麦再上麦生效，不自动中断通话。
4. 实际发送来自 SDK。未上麦或统计过期显示 --；编码未确认时会提示，不保证实际恒定192。
5. 恢复原版也要下麦再上麦。彻底移除则退出TT、移除注入项后重启。
